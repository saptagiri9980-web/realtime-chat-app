[# Real-time Chat App 💬

A scalable real-time chat application built with Java Spring Boot + WebSocket.

## ✨ Features
- Real-time messaging using WebSocket + STOMP
- Online users tracking
- Typing indicators
- Responsive UI

## 🛠️ Tech Stack
- Backend: Java 17, Spring Boot 3.2, Spring WebSocket
- Frontend: HTML5, CSS3, JavaScript, SockJS
- Build Tool: Maven

## 📦 How to Run
git clone https://github.com/saptagiri9980-web/realtime-chat-app.git
cd realtime-chat-app
./mvnw spring-boot:run

Open http://localhost:8080
